## 1. 前端问题

### 1.1 流水线卡「状态未上报」与健康卡「在线」自相矛盾

- **现象**：同一时刻，链路卡片显示灰色「状态未上报」，而下方健康卡显示绿色「在线」。
- **根因**：手机上报的 `telemetry.xrayLive` 是**数字 1/0**；流水线卡用 `xr === true` 判断（只认布尔），健康卡已做 `1 / '1'` 兼容 → 同一字段两处口径不一致。
- **修复**：流水线卡判断改为 `xr === true || xr === 1 || xr === '1'`（离线同理兼容 `0 / '0'`）。
- **验证**：线上同屏显示一致（两处均为「Xray 在线」）。

### 1.2 节点矩阵状态栏永远停在「等待探测结果」

- **现象**：55 个节点全部测完（旁注「已测 55」），状态栏仍是「● 节点清单已装载 · 等待探测结果」。
- **根因**：该文案是**静态 HTML**，全文件仅出现一次，没有任何 JS 更新逻辑。
- **修复**：改为中性文案「● 节点矩阵 · 手机端顺序探测」，不再暗示"尚未完成"。

### 1.3 右上角「X 秒前数据」虚增，与顶栏「数据 X 秒前」矛盾

- **现象**：默认 1 分钟采集模式下，右上角标签会从 0 一路涨到 60 秒；实测同时出现「数据 1 秒前」与「56秒前数据」。
- **根因**：该标签用"上次轮询基准 + 本地累加"计算，而轮询间隔是 60 秒；实际数据由手机每 6 秒推送，真实年龄 ≤ 6 秒。
- **修复**：优先使用实时推送的 `liveAgeS +（当前时间 − 上次推送时间）`，轮询基准仅作兜底。
- **验证**：实测右上角「2 秒前数据」与顶栏「数据 0 秒前」一致。

### 1.4 节点「数据陈旧」阈值与探测周期不匹配

- **现象**：一片节点变黄显示「数据陈旧」（实测 55 个中 21 个），与「已测 55」同屏，看起来像故障。
- **根因**：阈值写死 600 秒；而手机端逐节点探测一轮耗时在 **7~17 分钟**之间波动（受网络影响），队尾节点必然超过 600 秒。
- **修复**：改为**按轮次**判定：
  - 轮长 = 相邻节点实测间隔中位数 × 节点总数（夹在 300~3600 秒之间，动态计算）
  - ≤ 1 轮 = 绿「连通」；≤ 2 轮 = 黄「数据陈旧」；> 2 轮 = 灰「未探测」
  - **只有手机真正探到失败/超时（ok=false）才显示红色「不通」**
- **验证**：55 个节点恢复全绿；已知失效节点仍正确显示红色「不通」。

### 1.5 4 处引用了不存在的 DOM id（死代码）

- **现象**：表面无异常（写入静默失败）。
- **根因**：改版删除 UI 块后，写入代码保留：`riskBadge` / `hwBattery` / `hwBatteryStatus` / `hwSockets`。
- **修复**：删除这 4 段写入逻辑。
- **验证**：全量 id 交叉核查后"引用不存在的 id"归零；健康卡的电池/温度（另一套 id）显示正常。

### 1.6 首屏「0 个采样点」

- **现象**：刚打开大屏时，波形图旁显示「0 个采样点」，最长 1 分钟后才变成 30。
- **根因**：写标签的代码在图表数据填充之前执行。
- **修复**：在图表 `update()` 之后同步刷新该标签。

### 1.7 极速模式存在重复请求

- **现象**：不易察觉的额度浪费。
- **根因**：「2 秒轮询」与「每 10 秒槽位补抓 2 次」两套机制重叠，同一时刻重复取数。
- **修复**（按决策）：取消 2 秒轮询，极速模式改为**仅由 10 秒槽位双采驱动**；按钮改名「⚡ 10秒极速」，避免文案与实际行为不符。
- **验证**：模式切换正常，数据延迟保持 0~5 秒。

### 1.8 删除用户缺少二次确认

- **现象**：用户列表点「删除」立即生效，无确认步骤。
- **根因**：删除表单直接 POST。
- **修复**：服务端渲染与客户端重渲染两处都加 `onsubmit="return confirm(...)"`；确认文案中的用户名经安全处理（见 1.9）。

### 1.9 用户名字段未转义（存储型 XSS 风险）

- **现象**：名字里含 `<`、引号等字符时可能破坏页面结构；恶意构造可注入脚本。
- **根因**：服务端行渲染、客户端表格/排行榜/下拉框、以及内联进 `<script>` 的用户 JSON 均未做转义。
- **修复**：
  - 服务端新增 `escHtml` / `escJsAttr`，用于用户名、出口 IP、token、同步次数等外来文本；
  - 页面端新增 `escPage` / `safeName`，覆盖表格、排行榜、域名下拉、确认框文案；
  - 内联 JSON 额外转义 `< > &` 与行分隔符（U+2028/U+2029），防止提前闭合脚本块。
- **实现注意**：大屏页面整体位于**模板字符串**内，反斜杠会被提前处理，因此确认框文案改用"无引号/无反斜杠"的安全实现，并在本地渲染出页面后做语法与 id 校验。

## 2. 后端（Worker）问题

### 2.1 对象字面量中重复键 `totalSample`

- **现象**：功能正常（两处取值恰好相同），但属于埋雷。
- **根因**：同一对象里 `totalSample` 写了两次，后者覆盖前者；一旦只改其中一处就会静默失效。
- **修复**：删除多余的一行（保留由本轮计算赋值的那一处）。

### 2.2 每次打开大屏都会自动下发全速扫描

- **现象**：打开/刷新页面即触发手机 55 节点全速巡检（约 5.5 分钟），并产生 1 次 KV 写 + 1 次 KV 删。
- **根因**：页面加载 1.5 秒后自动 POST 扫描指令；与"仅手动触发"的注释相矛盾。
- **修复**（按决策）：**删除自动触发**，只保留「⚡ 手动刷新」按钮。
- **验证**：新开页面 24 秒后手机仍为常规节奏（nodeFast=0），KV 写入计数不变。

### 2.3 云端 KV 遗留键清理

- **现象**：KV 中存在早期版本留下的 5 个键（`stats:latest` 与若干 `user:*`），现代码已不读写。
- **根因**：历史架构遗留（实时数据已迁移到内存 + Cache API；用户库合并为单键）。
- **修复**：先导出这些键的值到本地备份，再逐个删除；清理后 KV 只剩 3 个 `noc:*` 键。
- **验证**：删除后全套接口冒烟通过（数据接口 200、无密码 401、订阅 200）。

### 2.4 规范问题（按决策不改，仅记录）

- `/api/report_traffic` 非 POST 返回 404（更规范应为 405）；
- `/admin` 未认证返回 200 + 登录页（更严格应为 401，但浏览器直接访问时体验更差）。

> 决策：保持现状，不影响功能。

## 3. 手机侧采集脚本整改

### 3.1 脚本副本治理（消除"改错文件"风险）

- **问题**：本地同时存在两份用途相同但内容不同的上报脚本；旧交接文档的说明已过期，容易改到不生效的那一份。
- **诊断方法**：通过 ADB 对手机与本地逐文件做 MD5 比对。
- **结论**：手机实际运行的是 `report_traffic.sh`（与本地逐字节一致）；另一份为过期副本。
- **处理**：过期副本重命名归档；同时发现手机上 `run_daemon.sh` 为旧版（缺少"启动后真实存活检查"等修复），已同步为新版并在手机保留原文件备份。

### 3.2 探测并发硬性 ≤ 2

- **问题**：手机上同时运行多个探测脚本（区域扫描、节点探测、边缘探针，手动刷新时再加全速扫描），峰值并发不受控；另发现 2 个重复的探针实例。
- **修复**：
  - 新增 `probe_gate.sh`：基于 `mkdir` 原子操作的**两个名额通行证**，探测前占位、测完释放，持有者被杀后名额可被自动回收；
  - 区域扫描、节点探测、边缘探针、全速扫描四个脚本全部接入；
  - 清理重复实例，重启后每个脚本仅保留 1 个实例。
- **验证**：
  - 4 个并发争抢 2 个名额的算法自测：峰值 = 2；
  - 100 秒采样（期间触发一次手动刷新制造最坏情况）：名额占用峰值 = 2、超限 0 次；
  - 探测数据仍正常推进（节点索引、六区时间戳按槽位更新）；
  - **隧道进程（xray / cloudflared / 看门狗）PID 全程未变，用户无断线**。

## 4. 附录：网络层排查结论（非代码缺陷）

排查"用户 OOKLA 测速时好时坏"时得到的数据，记录备查：

| 项目 | 结论 |
|---|---|
| 手机裸下载（家用链路） | 调整路由器前 17~47 Mbps 大幅抖动；调整后 **47~89 Mbps**，最低值显著抬升 |
| 5G 链路延迟抖动 | 仍然存在（数十毫秒级抖动），属蜂窝链路固有 |
| 隧道稳定性 | 长时间运行仅注册过 4 次（均为重启时），无异常重连 |
| 代理客户端"延迟测试"数字偏高 | 属**冷连接全链路耗时**（客户端→边缘→隧道→手机→目标站），非故障；浏览时连接复用，实际体验优于该数字 |

## 5. 验证方式（线上）

1. 三处 BUILD_ID 一致：源码常量、`/api/live` 返回、页面内嵌变量；
2. 接口冒烟：`/api/stats_data` 200、`/api/live` 200、`/api/rtt` 204、`/sub` 200、`/admin` 200、无密码 `401`；
3. 页面自检：内联脚本语法校验、DOM id 交叉核查、运行时错误探针无异常记录；
4. 数据自检：数据年龄保持个位数秒、六区时间戳按槽位推进、节点索引正常推进。

## 6. 回滚点

| 对象 | 回滚方式 |
|---|---|
| Worker 源码 | 部署器自动生成的 `worker_deploy.js.bak_before_deploy_*`；或使用全量备份目录 |
